# ☕ Java ile Yazılım Mimarisi | Software Architecture with Java

## 🇹🇷 Türkçe

### 📌 Proje Hakkında

Bu proje, Java programlama dili kullanılarak yazılım mimarisi prensiplerini ve tasarım yaklaşımlarını incelemek ve uygulamak amacıyla hazırlanmıştır.

Projenin amacı; sürdürülebilir, modüler, okunabilir ve bakımı kolay yazılımlar geliştirmek için temel yazılım mimarisi kavramlarını anlamak ve uygulamaktır.

### 🎯 Hedefler

* Yazılım mimarisi prensiplerini öğrenmek ve uygulamak
* Modüler ve yeniden kullanılabilir kod geliştirmek
* Katmanlı mimari ve tasarım prensiplerini incelemek
* Kod kalitesini ve sürdürülebilirliği artırmak

### 🛠️ Kullanılan Teknolojiler

* Java
* Object-Oriented Programming (OOP)
* Software Design Principles

## 🇬🇧 English

### 📌 About the Project

This project explores and applies software architecture principles and design approaches using Java.

The main goal is to understand and implement fundamental software architecture concepts to build maintainable, modular, readable, and scalable software applications.

### 🎯 Objectives

* Learn and apply software architecture principles
* Develop modular and reusable code
* Explore layered architecture and design principles
* Improve code quality and maintainability

### 🛠️ Technologies

* Java
* Object-Oriented Programming (OOP)
* Software Design Principles
